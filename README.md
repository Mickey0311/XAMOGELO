# Xamogelo — Conseil, Marketing & Transformation

Site vitrine premium pour **Xamogelo Conseil & Marketing**, agence marocaine basée à Casablanca.

Xamogelo accompagne les entreprises, institutions, dirigeants, leaders et talents dans leur croissance stratégique, humaine et digitale.

> **Conseil, communication, transformation.**

## 1. Vision du projet

Le site doit présenter Xamogelo comme un écosystème professionnel réunissant :

- le conseil stratégique ;
- le marketing et la communication ;
- le digital et la technologie ;
- l’image et l’influence ;
- la formation et le développement des compétences.

L’objectif n’est pas de créer une simple page de présentation, mais une expérience digitale premium qui transforme les visiteurs en prospects et en partenaires.

## 4. Direction artistique

### Ambiance générale

Le style recherché est un mélange de :

- cabinet de conseil premium ;
- agence digitale moderne ;
- média éditorial haut de gamme ;
- académie professionnelle.

Le site peut s’inspirer de la structure éditoriale et immersive de sites de groupes comme Sophos Côte d’Ivoire, sans copier leur identité, leurs contenus ou leur direction artistique.

### Mode sombre

Le mode sombre est l’expérience principale recommandée :

- fond noir bleuté ou bleu nuit ;
- textes blancs et gris froids ;
- bleu digital pour les éléments interactifs ;
- doré pour les détails premium ;
- orange pour les appels à l’action ;
- logo2.jpeg.

### Mode clair

Le mode clair doit rester disponible :

- fond ivoire, blanc cassé ou gris très clair ;
- textes bleu profond ;
- surfaces blanches ;
- bordures gris clair ;
- logo1.jpeg.

### Typographie

Titres :

- Playfair Display ;
- Cormorant Garamond ;
- Cinzel, si nécessaire pour des éléments spécifiques.

Texte courant :

- Manrope ;
- DM Sans ;
- Inter.

### Principes visuels

- hero immersif avec image, texture ou vidéo ;
- grandes typographies éditoriales ;
- images avec filtre sombre et dégradés ;
- cartes visuelles légèrement arrondies ;
- bordures fines et effets lumineux discrets ;
- animations lentes et élégantes ;
- navigation fixe et compacte ;
- logo réduit et toujours correctement intégré au fond ;
- footer sobre, professionnel et sans surcharge.

## 7. Fonctionnement du formulaire

Le formulaire doit :

1. Valider les champs côté client ;
2. Envoyer les données à l’API ;
3. Valider les données côté serveur ;
4. Envoyer un email à Xamogelo via Nodemailer ;
5. Utiliser l’adresse du visiteur comme adresse de réponse ;
6. Afficher un message de succès ou d’erreur ;
7. Ne jamais exposer les identifiants SMTP au navigateur.

Variables d’environnement prévues :

```env
SMTP_HOST=
SMTP_PORT=587
SMTP_USER=
SMTP_PASSWORD=
SMTP_SECURE=false
CONTACT_TO=contact@xamogelo.ma
```
